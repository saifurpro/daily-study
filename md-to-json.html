MD → JSON কনভার্টার ও এডিটর

Google Docs থেকে নামানো .md (বা আগের .json) ছেড়ে দিন, প্রিভিউতে যেকোনো লেখা বদলান, মুছুন বা নতুন সারি যোগ করুন, তারপর JSON নামিয়ে নিন।

📂 .md বা .json ফাইল এখানে ড্র্যাগ করুন (একাধিক হলেও চলবে)অথবা ক্লিক করে বেছে নিন
☁️ Google Drive ড্যাশবোর্ড — সংযুক্ত নয়
প্রথমবার সেটআপ (আলাদা নতুন স্ক্রিপ্ট — পুরনোটায় হাত দিতে হবে না)
  1. script.google.com → New project খুলুন।
  2. — সব পুরনো লেখা মুছে পেস্ট করুন। উপরের দুই লাইনে ফোল্ডার আইডি (ফোল্ডার লিংকের /folders/ এর পরের অংশ) ও আপনার গোপন পাসকোড বসান, তারপর Save।
  3. Deploy → New deployment → Web app: Execute as = Me, Who has access = Anyone → Deploy। অনুমতি চাইলে Authorize করুন (“Google hasn’t verified this app” এলে Advanced → Go to … চাপুন)।
  4. দেওয়া Web app URL কপি করে উপরের ঘরে বসান, পাসকোড দিন, “সংযোগ” চাপুন।
  5. পরে স্ক্রিপ্ট বদলালে Deploy → Manage deployments → ✏️ → New version দিতে হবে।
এখনো কোনো ফাইল নেওয়া হয়নি।
ফাইল ছাড়লে এখানে প্রিভিউ দেখা যাবে।
