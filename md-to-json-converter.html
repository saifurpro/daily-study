MD → JSON কনভার্টার ও এডিটর

Google Docs থেকে নামানো .md (বা আগের .json) ছেড়ে দিন, প্রিভিউতে যেকোনো লেখা বদলান, মুছুন বা নতুন সারি যোগ করুন, তারপর JSON নামিয়ে নিন।

📂 .md বা .json ফাইল এখানে ড্র্যাগ করুন (একাধিক হলেও চলবে)অথবা ক্লিক করে বেছে নিন
এখনো কোনো ফাইল নেওয়া হয়নি।
ফাইল ছাড়লে এখানে প্রিভিউ দেখা যাবে।
